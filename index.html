COMMON QUESTIONS

Frequently Asked Questions

Is Phoenix Smartboard completely free and offline?

Yes. Phoenix Smartboard runs 100% offline using client-side IndexedDB persistence and Service Workers. No internet connection or accounts required.

What is the .ps file format?

The .ps format is a portable, human-readable UTF-8 JSON bundle containing lesson metadata, page coordinates, vector strokes, and embedded media assets. It ensures your lessons are always yours and never locked to vendor cloud servers.

Can I import existing lesson files?

Yes! Phoenix Smartboard includes built-in converters to open PDF documents, Word (.docx) files, PowerPoint (.pptx) presentations, and earlier lesson archives.
